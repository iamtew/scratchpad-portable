Ruleset, not a product

Use your coding agent as a general assistant.

Assistants are convenient. So are coding agents. This is a small portable ruleset so Cursor and Claude stop treating every folder like the next startup MVP.

Drop the folder somewhere — cloud-synced is fine — and open it as a workspace. It becomes a scratchpad: notes, ideas, small scripts, a test-bed so experiments stay out of real projects. Independent subfolders, each with its own purpose. Not a singular project, not a git repo, not something to package or ship.

Download ZIP GitHub repo

How to use it

  1. Copy the scratchpad-portable folder somewhere.
  2. Optional: rename it to something useful.
  3. Open that folder as a workspace in Cursor or Claude.

Cursor

Rules live in .cursor/rules/ and stay on. Open the folder as the workspace root and the scratchpad identity applies.

Claude

CLAUDE.md imports @AGENTS.md, so Claude Code shares the same identity. Same folder, same rules.
