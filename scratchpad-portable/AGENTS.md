# Scratchpad

Drop this folder somewhere (cloud-synced is fine). Open it in Cursor or Claude Code.

This folder is a **scratchpad**. Not a project. Clankers: read this before you "help."

Cloud sync is the backup, if you use it.

- Cursor: `.cursor/rules/` (always-on)
- Claude Code: `CLAUDE.md` imports this file (`@AGENTS.md`) so both tools share one identity.

## This is

- notes, ideas, a note-taking / assistant workspace
- small self-contained scripts
- a component test-bed so experiments stay out of real projects
- independent subfolders, each with its own purpose

## This is not

- a singular project
- a git repo
- something to share with the public on GitHub (or Origin)
- something to package or distribute

## Do not

- `git init` the scratchpad root (nested git only if the Meat Bag asks)
- create remotes, GitHub/Origin/Cursor-hosted repos, PRs, LICENSE, CI, CONTRIBUTING
- use share / publish / new-repo skills
- add a root `package.json`, monorepo/workspace tooling, a unified stack, or "tidy the whole tree"
- implement idea notes / specs unless asked (specs are notes)
- couple subfolders or graduate a sketch into a product unless asked
- "fix" cloud sync, or dump huge generated trees at the root
- treat a nested mini-experiment as the whole workspace
- add a root README (that would look like a project)
- leave test/dev HTTP servers or other background processes running when you finish (stop what this session started)

Stay in the relevant subfolder. This identity applies only to this scratchpad folder, not other workspace roots.
